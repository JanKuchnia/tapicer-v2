# Project page template: `/realizacje/<marka>-<model>/`

**Goal:** show one real job in detail so it ranks for "<marka> <model> tapicerka" and proves skill.
**Primary keyword:** `<marka> <model> tapicerka` / `renowacja wnętrza <marka>`
**Min:** 300 words + 6 photos. **Quality gate: below that, don't publish; add it to the hub grid only.**
**Schema:** `CreativeWork` (or `Article`) with `ImageObject`s, `about` the vehicle, `BreadcrumbList`
**H1:** `<Marka> <Model> (<rok>) – <co zrobiono>`

## Sections
1. **Summary box:** make, model, year, services, materials, time it took (only if the client is happy to share)
2. **Stan przed:** problem and condition, with before photos
3. **Co zrobiliśmy:** steps, materials, challenges (the craft detail is what matters)
4. **Efekt:** after photos, as a gallery with captions
5. **Opinia klienta:** only if real and permitted
6. **Linked services:** cards for the service pages used
7. **Podobne realizacje:** 2–3 projects of the same make or era
8. **CTA**

## Notes
- Each one replaces an old per-make `.html` page, so add the 301 in the redirect map
- Alt text is specific: "Fotele Porsche 911 obszyte skórą koniakową, widok z boku"
