## What the client already has

- Per-make and per-service pages, which suit long-tail search. Keep that equity via redirects.
- A heritage story (saddlery → carriages → classic cars) no one else tells.
- A real flagship project (Cadillac limousine).

## Keyword gaps to fill

- **Service-area pages:** Skórzana Alchemia targets towns; we have only the site title. Add Kraków and Myślenice pages, more after [CONFIRM].
- **Steering-wheel depth:** a dedicated page on perforated vs smooth leather, alcantara, airbag cover and stitching colours.
- **Pricing intent ("ile kosztuje"):** competitors' handling unknown. A `/cennik/` page explaining cost factors captures the query without publishing numbers.
- **Classic-car national queries:** likely low competition. Verify with SERP checks.
